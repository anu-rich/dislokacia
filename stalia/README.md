# Stalia — калькулятор сталийного времени и демереджа

Готовый продукт: сайт, калькулятор, приложение для телефона и платная версия Pro. Сайт и калькулятор — набор статических файлов: работают без сервера и без ежемесячных расходов. Сервер нужен только для чтения документов (см. ниже).

- Калькулятор: `app/` — все условия сталии, шкала времени, таймшит по дням, документ для печати.
- Из документов: фото или PDF чартера и стейтмента → замазать лишнее → условия и время читаются сами → проверить и поправить в обычной форме.
- Языки: английский, русский, казахский, украинский, турецкий, греческий, китайский — интерфейс, печатный документ и главная страница сайта.
- Сайт-витрина: `index.html` и папки `ru/`, `kk/`, `uk/`, `tr/`, `el/`, `zh/` — с ценами; статьи есть на английском, русском и казахском.
- Телефон: ставится с сайта на Android и iPhone и работает без интернета; сборки для магазинов — в `mobile/`.
- Деньги: бесплатная версия для всех, Pro по подписке — ключ активируется в калькуляторе.

## На чём он зарабатывает

Считать можно бесплатно и без ограничений — это приводит людей. Платят за то, что уходит контрагенту:

| | Free | Pro |
|---|---|---|
| Расчёты, шкала времени, таймшит на экране | да | да |
| Документ для печати | со строкой «бесплатная версия» | чистый, на бланке компании с логотипом |
| Сохранённые расчёты | 3 | без ограничений, плюс файлы-копии |
| Портов в рейсе | 2 | сколько угодно |
| Выгрузка таймшита в Excel (CSV) | нет | да |
| Чтение документов | 2 в день, модель Haiku | 20 в день, модель Sonnet |

Цены по умолчанию: 19 $ в месяц или 149 $ в год; для Казахстана 9 900 ₸ и 79 000 ₸. Меняются в одном файле — `app/config.js`.

Что я проверил по рынку (поиск в ноябре 2026): платные онлайн-калькуляторы сталии стоят около 35 $ в месяц за модуль, бесплатные считают только арифметику без таймшита, на русском и казахском готовых аналогов я не нашёл.

Чего обещать нельзя: продукт сам по себе денег не приносит. Это узкий рабочий инструмент для брокеров, операторов, агентов и трейдеров. Первые оплаты приходят от людей, которым вы его показали лично; поиск и магазины приложений начинают приводить посетителей через месяцы.

## Запуск по шагам

### 1. Вынести в свой репозиторий

Сейчас папка `stalia/` лежит в ветке `ccr-d76ef0d6-3stcf2` репозитория с дашбордом. Продукту нужен отдельный репозиторий: создайте его на GitHub и перенесите туда содержимое папки `stalia/` (всё, что внутри, должно оказаться в корне нового репозитория).

### 2. Выложить сайт

Самый простой бесплатный вариант — GitHub Pages: в новом репозитории Settings → Pages → Deploy from a branch → ветка `main`, папка `/ (root)`. Через минуту сайт откроется по адресу вида `https://имя.github.io/репозиторий/`.

### 3. Прописать адрес сайта

```bash
node tools/site.js https://ваш-адрес
```

Команда впишет адрес во все страницы, создаст `sitemap.xml` и `robots.txt` для поисковиков. Когда купите свой домен — выполните её ещё раз с новым адресом.

### 4. Вписать свои контакты

В `app/config.js`: `contactEmail` (обязательно) и `telegram` (по желанию). Сейчас там заглушка `hello@example.com` — пока она стоит, покупатели не смогут вам написать.

Проверьте и поправьте под себя страницы `privacy.html` и `terms.html`: условия возврата и ответственность написаны как разумный шаблон, но продавец — вы.

### 5. Подключить оплату

**Картой, автоматически — Lemon Squeezy.** Сервис принимает карты по всему миру, сам выдаёт покупателю лицензионный ключ и перечисляет деньги на банковский счёт. Казахстан есть в их списке стран для банковских выплат (проверено по их документации в ноябре 2026). Комиссию и условия смотрите на их сайте; магазин активируют после проверки вашего сайта.

1. Создайте магазин и товар «Stalia Pro» с подпиской в двух вариантах: на месяц и на год.
2. В товаре включите Generate license keys, лимит активаций — 3.
3. Скопируйте ссылки на оплату обоих вариантов в `app/config.js` → `checkout`.
4. Там же заполните `lemonSqueezy`: `enabled: true`, `storeId`, `productIds`.
5. В письме покупателю задайте ссылку на кнопке: `https://ваш-адрес/app/?license_key=[license_key]` — тогда Pro включается одним нажатием.

Как это работает в калькуляторе, я проверил на настоящем сервере Lemon Squeezy: неизвестный ключ отклоняется, ключ от чужого магазина не принимается. Полный путь «оплата → ключ → Pro» с настоящей оплатой проверьте сами первой тестовой покупкой.

**По счёту или переводом — ключ выдаёте вы.**

```bash
node tools/keygen.js issue --name "ТОО Пример" --days 365
```

Команда печатает ключ; отправьте его покупателю письмом. Список выданных ключей ведётся в `tools/.private/issued.csv`.

Чтобы принимать деньги от компаний, нужен статус, позволяющий выставлять счета (обычно ИП). Налоги и оформление уточните у бухгалтера — здесь я не советчик.

### 6. Включить чтение документов

Это единственная часть продукта, которая стоит денег при работе: каждое чтение — запрос к модели Claude.

1. Получите ключ API Anthropic и поставьте в их кабинете месячный лимит расходов.
2. Разверните маленький сервер из папки `server/` — по шагам в `server/README.md` (Render или Cloudflare Workers).
3. Впишите его адрес в `app/config.js` → `ai.endpoint`. Для приложения после этого соберите APK заново.

Пока адрес не вписан, чтение работает в режиме «свой ключ»: в окне «Из документов» человек вставляет собственный ключ Claude API, и страницы уходят с его устройства прямо в Anthropic — без вашего сервера и за его счёт. Ключ хранится только на его устройстве. Так можно пользоваться чтением самому и запустить сайт вообще без сервера; сервер нужен, когда вы хотите дать чтение тем, у кого своего ключа нет (бесплатные чтения и Pro). Скрыть режим можно настройкой `ownKey: false` в `app/config.js`.

Сколько это стоит — замерено на настоящем API на образцах: комплект из четырёх страниц читается за $0,009 на Haiku (бесплатные чтения) и за $0,09 на Sonnet (чтения с Pro), за 20–50 секунд. Модели и лимиты меняются в настройках сервера. Таблица замеров — в `server/README.md`.

Что важно знать: чтение проверено с настоящим ключом только на образцах из `samples/` — они чистые. Первое чтение настоящего документа сверьте с оригиналом сами.

### 7. Сохранить мастер-ключ

Файл `tools/.private/stalia-private-key.pem` — это ключ, которым подписываются лицензии. Он не попадает в git. Тот, у кого есть этот файл, может выпускать лицензии Pro.

- Сохраните его копию в надёжном месте.
- Тот ключ, что создан в этой сессии, я передал вам файлом. Если не уверены, что он остался только у вас, создайте новый до первых продаж: `node tools/keygen.js init --force --replace`.

### 8. Проверить перед запуском

```bash
cd server && npm install && cd ..   # один раз: нужно для проверок сервера чтения
npm test                    # 82 проверки расчёта, лицензий, текстов, ссылок и сервера чтения
node tests/e2e/smoke.js     # около 120 проверок сайта и калькулятора в настоящем браузере (нужен Playwright)
node tests/e2e/import.js    # около 110 проверок «Из документов»: загрузка, замазывание, чтение, перенос в расчёт
node tools/check-lang.js tr # проверка одного языка: строки и главная страница
```

## Первые клиенты

Порядок, в котором это обычно срабатывает:

1. **Десять знакомых из отрасли.** Попросите не купить, а посчитать на нём реальный рейс и сказать, что не так. Ошибки и непонятные места исправляются за день.
2. **Профильные чаты и LinkedIn.** Не «у меня новый сервис», а разбор: один судозаход при шести оговорках даёт от 11 500 $ демереджа до 6 250 $ диспача. Готовые тексты — в `marketing/`.
3. **По пять личных сообщений в день** небольшим брокерам, агентам, операторам. Шаблоны там же.
4. **Статьи.** Три уже есть на сайте. Добавляйте по одной в неделю: демередж у танкеров, реверсивная сталия, когда нотис действителен.
5. **Магазины приложений.** Карточка в Google Play — это ещё один бесплатный источник посетителей. Инструкция в `mobile/README.md`.

Смотреть нужно на одну цепочку: открыл калькулятор → досчитал до конца → открыл документ для печати → купил Pro. Там, где она рвётся, и надо чинить.

## О рисках прямо

- **Работа по найму в этой же отрасли.** Проверьте трудовой договор и кодекс этики компании: разрешена ли сторонняя деятельность и нужно ли о ней сообщать. В продукте нет ни одной цифры работодателя, и так должно остаться.
- **Это не юридическая консультация.** Калькулятор считает по правилам, которые выбрал пользователь; об этом сказано в самом продукте и в условиях.
- **Защита Pro рассчитана на честных людей.** Всё выполняется в браузере, поэтому технически её можно обойти. Для делового инструмента этого достаточно.
- **Имя Stalia — рабочее.** Свободен ли домен и не занят ли товарный знак, я проверить не мог.
- **Чтение документов ошибается.** Модель может неверно прочитать цифру, особенно рукописную или на плохом фото. Поэтому после чтения всё попадает в обычную форму, сомнительное подсвечено, и пользователь подтверждает сам. Обещать клиентам «читает без ошибок» нельзя.
- **Чтение стоит денег вам.** Лимиты на сервере и лимит расходов в кабинете Anthropic — обязательны с первого дня.
- **Документы уходят третьей стороне.** Страницы обрабатывает Anthropic. Замазывание происходит на устройстве до отправки, но незамазанное модель видит. Это честно написано в продукте и в `privacy.html`.
- **Переводы на украинский, турецкий, греческий и китайский сделаны моделью** по отраслевым глоссариям и проходят автоматические проверки, но носитель языка из отрасли их не вычитывал.

  vendor/pdfjs/   чтение PDF (PDF.js, лицензия Apache 2.0)

server/         сервер чтения документов (нужен только для «Из документов»)

marketing/      тексты постов, писем и карточек для магазинов
tools/

  site.js         адрес сайта во всех страницах, переключатель языков, sitemap

  sync-server.js  копии общих файлов для сервера чтения

## Как менять продукт дальше

Откройте новую сессию Claude Code в репозитории продукта и опишите задачу словами, например:

- «Поменяй цены на 25 $ и 199 $».
- «Добавь статью про реверсивную сталию на трёх языках».
- «Собери APK с новой версией».
- «Добавь валюту и поле для номера чартера».
- «Добавь арабский язык» (потребуется письмо справа налево — отдельная работа).
- «Разверни сервер чтения: вот ключи» — ключи вводятся в защищённой форме, не в чате.

После любых изменений запускайте `npm test`.
