# Stalia для Android и iPhone

Это тот же калькулятор, упакованный как приложение (Capacitor 8). Код один: всё, что меняется на сайте, попадает в приложение следующей сборкой.

## Три способа дать людям приложение

| Способ | Что нужно | Состояние |
|---|---|---|
| **Установка с сайта** (Android и iPhone) | Только опубликованный сайт | Работает. Проверено в браузере: ставится, открывается без интернета |
| **Android: APK и Google Play** | Аккаунт разработчика Google, 25 $ один раз | APK собирается и собран; на реальном телефоне я запустить его не мог — проверьте установкой |
| **iPhone: App Store** | Mac с Xcode и Apple Developer, 99 $ в год | Проект создан, но ни разу не собирался (нужен Mac) |

### Установка с сайта — уже сейчас

На телефоне открыть калькулятор и нажать «Установить приложение»:

- Android (Chrome): меню ⋮ → «Установить приложение».
- iPhone (Safari): «Поделиться» → «На экран „Домой“».

Иконка появляется на главном экране, калькулятор открывается на весь экран и работает без интернета. Магазины и аккаунты не нужны.

## Сборка Android

Нужны Node 22+, JDK 21 и Android SDK (платформа 36).

```bash
cd stalia/mobile
npm install
npm run android:debug
# готовый файл: android/app/build/outputs/apk/debug/app-debug.apk
```

Этот файл можно переслать себе на телефон и установить (Android попросит разрешить установку из этого источника). Он подписан тестовым ключом и годится для проверки, не для магазина.

### Публикация в Google Play

1. Зарегистрировать аккаунт в Google Play Console.
2. Один раз создать ключ подписи и сохранить его в надёжном месте:
   ```bash
   cd stalia/mobile/android
   keytool -genkeypair -v -keystore stalia-upload.jks -alias stalia -keyalg RSA -keysize 2048 -validity 10000
   ```
3. Рядом создать файл `keystore.properties` (в git он не попадает):
   ```
   storeFile=stalia-upload.jks
   storePassword=пароль
   keyAlias=stalia
   keyPassword=пароль
   ```
4. Собрать пакет для магазина: `npm run android:release` → `android/app/build/outputs/bundle/release/app-release.aab`.
5. Загрузить `.aab` в Play Console, заполнить карточку приложения и анкеты.

Для каждой новой загрузки увеличивайте `versionCode` и `versionName` в `android/app/build.gradle`.

## «Из документов» в приложении

- Настройки приложение хранит внутри себя. Чтобы в нём заработало чтение документов, сначала впишите адрес сервера чтения в `app/config.js` (`ai.endpoint`), потом соберите приложение заново. В сборке без адреса экран открывается, страницы добавляются и замазываются, но чтение отвечает «ещё не подключено».
- Кнопка «Сфотографировать» открывает штатную камеру телефона. Отдельного разрешения на камеру приложение для Android не просит; на iPhone система спросит доступ к камере при первом снимке — текст запроса лежит в `ios/App/App/Info.plist`.
- Чтение PDF встроено в приложение (PDF.js) и работает без интернета; интернет нужен только для самого чтения.
- На настоящем телефоне я это не запускал: проверена веб-часть приложения в эмуляции телефона в браузере.

У новых личных аккаунтов Google перед публикацией требует закрытое тестирование с группой тестировщиков; точные условия на момент регистрации смотрите в Play Console.

## Сборка iPhone

Только на Mac:

```bash
cd stalia/mobile
npm install
npm run ios:open        # откроет проект в Xcode
```

В Xcode выбрать свою команду (Team), проверить Bundle Identifier и сделать Product → Archive → загрузить в App Store Connect.

Чего в iOS-сборке пока нет: печати таймшита в PDF (кнопка скрыта). В версии, установленной с сайта через Safari, печать делает сам браузер.

## Что отличает сборку для магазинов

`scripts/build-web.js` копирует калькулятор в `www/` и включает два переключателя:

- `native` — убирает то, что в приложении не работает: установку с сайта, выгрузку файлов, ссылку на сайт;
- `store` — убирает цены и ссылки на покупку. Pro включается лицензионным ключом.

Второе сделано из-за правил Google Play и App Store: за цифровые функции внутри приложения нельзя брать оплату в обход их платёжных систем и нельзя вести пользователя на внешнюю оплату. Если захотите продавать подписку прямо в приложении, придётся подключать Google Play Billing и Apple In-App Purchase — магазины берут с этих продаж комиссию.

## Идентификатор приложения

Сейчас это `app.stalia.laytime`. Он становится постоянным после первой публикации, поэтому поменяйте его заранее, если выберете другое название:

- Android: `applicationId` в `android/app/build.gradle` и `appId` в `capacitor.config.json`;
- iPhone: Bundle Identifier в Xcode.

## После изменений в калькуляторе

```bash
npm run sync            # обновить копию калькулятора внутри приложений
npm run android:debug   # или android:release
```

Иконки и заставка лежат в `assets/`; после замены картинок выполните `npm run icons`.
