# Образцы документов

Выдуманные документы для пробы функции «Из документов». Они описывают встроенный пример «Пшеница, Новороссийск — Александрия», поэтому правильное чтение даёт известный результат: демередж 23 841,93 $.

- `charter-party-recap.pdf` — рекап фиксации и райдер, две страницы.
- `sof-novorossiysk.png` — стейтмент порта погрузки, чистый скан.
- `sof-alexandria.jpg` — стейтмент порта выгрузки, «фото» под углом.
- `sof-alexandria-by-hand.png` — тот же стейтмент, заполненный рукописным шрифтом.

Как пробовать: в калькуляторе «Из документов» → рекап в первое окно, оба стейтмента во второе → замазать, например, названия сторон и ставку → «Прочитать документы».

Файлы создаёт `tests/e2e/sample-docs.js`; настоящих данных в них нет.
