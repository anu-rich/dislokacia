# Сервер чтения документов

Маленький сервер для функции «Из документов». Он принимает страницы — уже с закрашенными на устройстве пользователя областями, — передаёт их модели Claude и возвращает прочитанные условия чартера и время событий. Сам ничего не хранит.

Без него всё остальное в Stalia работает как раньше. В самой функции «Из документов» можно добавить страницы и замазать лишнее, но кнопка «Прочитать документы» ответит, что чтение ещё не включено.

## Что понадобится

1. **Ключ API Anthropic.** [console.anthropic.com](https://console.anthropic.com) → API keys → создать ключ. Пополните баланс и сразу поставьте месячный лимит расходов в настройках организации: это ваш жёсткий предохранитель.
2. **Место, где сервер будет работать.** Ниже два варианта. Оба я описал по общим правилам этих площадок, сам на них не разворачивал: названия кнопок могли измениться.

## Вариант А. Render — без командной строки

1. [render.com](https://render.com) → New → Web Service → подключите GitHub-репозиторий продукта.
2. Root Directory: `server`. Build Command: `npm install`. Start Command: `npm start`.
3. В разделе Environment добавьте переменные:
   - `ANTHROPIC_API_KEY` — ваш ключ;
   - `ALLOWED_ORIGINS` — адрес сайта, например `https://stalia.example`;
   - `TRUST_PROXY` — `1`.
4. После развёртывания откройте выданный адрес в браузере. Должно появиться `{"ok":true,"service":"stalia-reader","ready":true,…}`. Если `ready` равно `false`, ключ не подхватился.

На бесплатном плане сервис засыпает без запросов, и первое чтение после паузы идёт заметно дольше. Счётчики лимитов живут в памяти и обнуляются при перезапуске.

## Вариант Б. Cloudflare Workers — из командной строки

```bash
cd server
npm install
npx wrangler login
npx wrangler secret put ANTHROPIC_API_KEY     # вставить ключ, когда спросит
npx wrangler deploy
```

Адрес сайта и лимиты задаются в `wrangler.toml`. Чтобы лимиты были общими для всех копий сервера, создайте хранилище: `npx wrangler kv namespace create LIMITS` — и впишите выданный id в `wrangler.toml` (там есть закомментированный блок).

На бесплатном плане Cloudflare жёстко ограничено процессорное время на запрос: чтение многостраничных документов может не уложиться. Тогда нужен платный план.

Worker я проверил в локальной среде Cloudflare (`npx wrangler dev`) с «двойником» модели: чтение проходит, лимиты срабатывают. В само облако Cloudflare я его не выкладывал.

## Подключить к сайту и приложению

В `app/config.js`:

```js
ai: { endpoint: 'https://адрес-вашего-сервера/', maxPages: 20 },
```

Для сайта этого достаточно. Приложение для телефона хранит настройки внутри себя, поэтому APK после этого нужно собрать заново (`mobile/README.md`).

## Настройки

Все задаются переменными окружения; образец — `.env.example`.

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | ключ API; без него чтение выключено |
| `ALLOWED_ORIGINS` | пусто | адреса сайтов, которым разрешено обращаться (через запятую); пусто — любым. Приложения для телефона разрешены всегда |
| `STALIA_MODEL` | `claude-sonnet-5-5` | модель для чтений с лицензией Pro |
| `STALIA_MODEL_FREE` | `claude-haiku-5-5` | модель для бесплатных чтений |
| `STALIA_EFFORT` | `high` | тщательность: `low`, `medium`, `high`, `xhigh`, `max` |
| `FREE_PER_DAY` | `2` | бесплатных чтений в день на посетителя; `0` — чтение только для Pro |
| `PRO_PER_DAY` | `20` | чтений в день на одну лицензию Pro |
| `PRO_PER_MONTH` | `200` | чтений в месяц на одну лицензию Pro |
| `GLOBAL_PER_DAY` | `150` | чтений в день на всех вместе |
| `MAX_PAGES` | `20` | страниц в одном чтении (то же число — в `app/config.js`) |
| `MAX_BODY_MB` | `24` | наибольший размер запроса |
| `TRUST_PROXY` | `0` | `1`, если сервер стоит за прокси (Render, nginx): тогда адрес посетителя берётся из заголовка прокси |
| `LS_STORE_ID`, `LS_PRODUCT_IDS` | пусто | магазин Lemon Squeezy, если Pro продаётся через него (те же числа, что в `app/config.js`) |

Чтобы все читали одной моделью, впишите одно и то же имя в `STALIA_MODEL` и `STALIA_MODEL_FREE`.

## Сколько стоит чтение

Оценка по опубликованным ценам моделей; настоящих вызовов с ключом я не делал.

| | Haiku 5.5 | Sonnet 5.5 |
|---|---|---|
| Цена за миллион токенов, вход / выход | $0,10 / $0,50 | $2 / $10 |
| Рекап 2 стр. + стейтмент 2 стр. | ≈ $0,005 | ≈ $0,10 |
| 20 страниц | ≈ $0,01–0,07 | ≈ $0,30 |

Страница занимает около 4,6 тыс. токенов, инструкция и схема ответа — около 6 тыс., ответ с рассуждением — 4–8 тыс. У Haiku запросы длиннее 100 тыс. токенов считаются по тарифу в пять раз выше; 20 страниц находятся у этой границы.

## Как проверено

- `npm test` в корне проекта: сервер работает с «двойником» модели. Проверяются формат запроса к API, лимиты, лицензии, отказы модели, возврат попытки при сбое.
- `node tests/e2e/import.js`: вся цепочка в настоящем браузере — сайт, этот сервер, SDK Anthropic — тоже с «двойником» модели.
- Пробное чтение: образцы документов (рекап, два стейтмента, вариант с замазанными названиями и ставкой, стейтмент рукописным шрифтом) прочитали агенты на моделях семейств Sonnet и Haiku по той же инструкции. Оба дали точный результат (демередж 23 841,93 $) и не стали угадывать замазанное.

Не проверено: вызов настоящего API с вашим ключом и чтение настоящих документов, особенно написанных от руки и снятых на телефон. Первое чтение после запуска сделайте сами и сверьте с оригиналом.

## Что сервер знает о пользователях

- Страницы и ответ модели не сохраняются. В журнал пишутся время, тариф (free или pro), число страниц, размер запроса, длительность и число токенов.
- Для бесплатного лимита сервер держит в памяти не сам IP-адрес, а его хеш; на следующий день он не нужен.
- Изображения обрабатывает Anthropic на условиях для бизнес-клиентов. На странице `privacy.html` это описано так, как я знаю их политику; перед запуском сверьте с действующей редакцией на их сайте.

## Если меняются ключи лицензий

Сервер проверяет ключи Pro теми же открытыми ключами, что и сайт; их копия лежит в `src/public-keys.js`. Команда `node tools/keygen.js init` обновляет её сама. После этого сервер нужно развернуть заново.
